## 이번 추가 선별

- 원래 경로의 자체 문서·표 13개, 분석 그래프 PNG 12개, 시뮬레이터 영상에서 추출한 JPG 43개를 추가했다. 분석 저장소 67개와 원본 보존소의 archive 재조립 안내 1개이며 모델이나 archive payload는 추가하지 않았다.
- 선별 파일은 총 1,071개다. 기존 1,003개의 출처·내용·Git mode는 보존했다. 전체 1,054개가 원본 바이트 동일하고 17개는 기존 개인 Windows 프로필 경로 블라인드본이다. 이번 68개에는 추가 블라인드가 필요하지 않았다.
- PNG 12개와 JPG 43개는 모두 실제 화면과 메타데이터를 확인했다. 자체 그래프 또는 시뮬레이터 렌더이며 식별 가능한 계정·OS 화면은 발견하지 못했다. PNG에는 Matplotlib 버전 정보만 있었고 JPG에는 EXIF/XMP/IPTC/ICC/Comment segment가 없었다. 메인이 그래프와 contact sheet 표본을 별도 확인했다.
- 이전 Git 파일과의 대응을 찾지 못해 보류했던 Round-2 H1 및 Round-3 Go2 자체 기술 보고서를 보존된 Release 원본에서 다시 확인했다. 원본 백업의 asset manifest SHA와 대조했으며, 보고서만 선별한다. 원래 제목·본문·파일명은 바꾸지 않는다.
- 두 보고서를 게시한 뒤 개별 Release 총 39건·105 asset의 원격 크기·SHA와 제목·본문 대조도 통과했다. 아래 37건·103 asset 개인정보 검사는 추가 전 범위이며, 새 보고서 2건과 원래 설명문은 별도 직접 읽어 확인했다.
