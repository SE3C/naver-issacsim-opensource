# NCRC 2026 검증된 프로젝트 현황

## 기술 요약

현재 저장소에서 확인되는 것은 **대회 규정 분석, 서버 백업 코드, 영상 분석 보고서, 전략·검증 설계 문서, 세 저장소의 역할 분리와 첫 H1 공식 서버 실행의 검토 결과**다. 실제 policy·checkpoint·env·report·영상 원본은 원본 저장소에 있고 분석 저장소에는 근거 등급을 붙인 결과 문서가 있다. 다만 전체 학습 로그·TensorBoard·GPU 시계열, evaluator 측정 결과와 Optuna trial은 아직 없다. 따라서 첫 실행의 파이프라인·환경 사실 외에 정책 성능이나 현재 로컬 실행환경 성능까지 확대해 결론 내리지 않는다.

이 문서는 이전 통합정리에서 저장된 근거로 확인할 수 없는 로컬 경로·하드웨어·설치 버전·실행 성공 주장·시간 추정·예시 점수를 제거한 사실 기록이다. 실행 전략은 [프로젝트 현황과 증거 기반 실행 전략](<../../research/planning/05_PROJECT_STATUS_AND_EVIDENCE_BASED_STRATEGY.md>), 실제 H1 진단 명령은 [H1 공식 서버 기준선 진단 가이드](<../../research/planning/06_H1_OFFICIAL_SERVER_BASELINE_DIAGNOSTIC.md>)를 따른다.

## 서버 백업 코드에서 확인되는 사실

### 공통 PPO 설정

백업의 H1·Go2 `agent_cfg.py`에는 모두 다음 값이 있다.

| 설정 | H1 | Go2 |
| --- | ---: | ---: |
| `num_steps_per_env` | 24 | 24 |
| `max_iterations` | 5000 | 5000 |
| `save_interval` | 100 | 100 |

이 값은 백업 코드의 기본값이다. 실제 공식 서버 실행값이나 제출 정책의 설정이라는 뜻은 아니다.

### README에 기록된 실행 인터페이스

| 구분 | H1 | Go2 |
| --- | --- | --- |
| task | `Humanoid-v0` | `Quadruped-v0` |
| README 학습 예 | `--num_envs 4096 --max_iterations 10000 --headless` | 동일 |
| 학습 후 정리 | `model_best.pt`, `env.yaml`, 조건부 `report.html` | 동일 구조 |
| play 후 export | `policy.pt`, `policy.onnx`, 영상 | 동일 구조 |

README의 명령은 백업 시점의 안내다. 실제 공식 서버에서는 `train.py --help`와 배포 파일을 먼저 확인해야 한다.

### checkpoint 선별과 정책 export는 별도 단계다

H1·Go2 `_finalize.py`는 TensorBoard의 `Train/mean_reward` 계열 값을 사용해 best checkpoint를 고르고 `model_best.pt`와 `env.yaml`을 `exported/`에 정리한다. 각 README는 `play.py` 실행 후 `policy.pt`가 생성된다고 설명한다.

따라서 백업 코드 기준으로 다음 두 파일은 같은 의미가 아니다.

```text
model_best.pt = 학습 checkpoint
policy.pt     = play 단계에서 export된 정책
```

`Train/mean_reward`로 고른 checkpoint가 공식 평가에서 가장 높은 점수를 받는다는 근거는 저장소에 없다.

## 원문에서 채택하지 않은 내용

다음 내용은 현재 저장 근거로 재현하거나 확인할 수 없어 삭제했다.

- 특정 PC의 GPU가 RTX 3060 12GB라는 주장
- 특정 Windows 경로에 Isaac Sim 6.0.1 RC가 설치됐다는 주장
- 별도 백업 경로의 Isaac Lab 2.3.2 설치·실행 상태
- Isaac Lab 3 설치 완료 여부와 특정 beta 버전 선택
- 과거 명령의 성공·실패 원인에 대한 대화 기반 결론
- H1과 Go2 중 어느 로봇을 먼저 해야 하는지에 대한 확정 순서
- 보관 로그 없이 계산한 장기 학습 예상시간
- 100시간의 구체적인 비율 배분
- 예시 leaderboard의 reward·proxy·fall-rate 숫자
- 아직 실행되지 않은 evaluator와 Optuna를 구현 완료로 읽을 수 있는 표현
- 로컬 환경에서 학습한 정책의 성능 또는 공식 서버와의 성능비

이 항목을 다시 추가하려면 명령 출력, 버전 파일, GPU 로그, 학습 로그, 정책 hash 또는 evaluator 결과처럼 재검토할 수 있는 증거가 필요하다.
