# 로봇 정책 실험에서 얻은 방법론

이 문서는 자체 실험을 거치며 정리한 판단 원칙이다. 대회 강의·규정·운영진 대화 원문을 제공하거나 특정 비공개 점수를 복제하지 않는다.

## 설정과 실행을 분리한다

- 설정은 전체 resolved parameters로 저장하고, 사람용 표시명은 그 설정을 대신하지 않는다.
- 실제 학습 한 번마다 Run을 만든다. seed, 환경 수, source commit, 실제 학습량과 종료 상태를 기록한다.
- fresh와 resume가 같은 최종 설정을 가져도 같은 실행은 아니다. 부모 checkpoint SHA, 부모 Run, 전환 전후 설정과 복원 상태를 남긴다.
- 실제 제출에 사용한 설정만 별도의 immutable submission snapshot으로 동결한다. 후보라는 이유로 다음 제출 번호를 미리 만들지 않는다.

## 학습 지표와 정책 평가를 구분한다

학습 reward는 가중치가 다른 설정 사이의 품질 순위가 아니다. 학습 중 접촉 종료 비율도 고정 평가의 생존율과 같지 않다. 학습은 탐색·변하는 지형·커리큘럼을 포함할 수 있고, 사후 평가는 고정 조건과 deterministic inference를 사용할 수 있다.

생존·전진·횡이동·회전·정지·험지 진행을 나눠 본다. 오래 살아도 명령을 수행하지 않을 수 있고, 평균 추종 오차가 낮아도 일부 지형에서 정체할 수 있다. 합성 점수만 기록하지 말고 구성 지표와 실패 시점도 보존한다.

## 비교의 질문을 먼저 정한다

설정 차이, 학습량 차이, 학습 seed 변동성, 부모 계보 차이를 한 이름으로 합치지 않는다. 짧은 학습에서 약했던 후보가 오래 학습한 기준보다 나쁘다는 것만으로 설정 자체를 탈락시키지 않는다. 반대로 추가 학습이 언제나 개선된다고 가정하지 않는다.

같은 부모에서 reward를 바꾼 분기와 바꾸지 않은 continuation을 비교하면 그 출발 정책에서의 전환 효과를 볼 수 있다. 이는 fresh 설정의 일반적인 우위와는 다른 질문이다. 독립 학습 반복과 평가 seed 반복도 서로 대체하지 않는다.

## 원본과 공개용 사본을 구분한다

학습 archive, checkpoint, TensorBoard, console/exit code, configuration과 source identity를 연결한다. 학습 완료·평가 완료·보고서 수신·실제 제출·공식 결과를 별도 상태로 기록한다.

공개를 위해 원본 evidence를 덮어쓰지 않는다. 공개용으로 경로 등을 제거한 사본에는 원본 식별자와 변환 사실을 남기되, 비공개 자료나 자격증명 자체를 함께 노출하지 않는다.

## 영상 캡처 오류는 정책 실패와 분리한다

고정 간격으로만 프레임을 뽑으면 주기적인 검정/정상 교대 프레임을 전체 검정 영상으로 오판할 수 있다. 연속 프레임과 홀짝·시간 분포를 함께 확인하고 캡처 품질과 로봇 행동을 구분한다. 디코딩에 성공했다는 사실만으로 캡처가 정상임을 보장하지 않는다.

이 방법론은 개선을 보장하는 평가식이 아니다. 외부 성적과 자체 평가가 어긋나면 먼저 집계·명령·시나리오·종료 처리·정규화와 실행 provenance를 확인하고, 결과를 본 뒤 유리한 지표만 골라 해석하지 않는다.
