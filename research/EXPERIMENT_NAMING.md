# Experiment naming — current rule

This page governs **current names**. Question-by-question navigation, including legacy aliases, is in [Experiment directory index](<experiments/README.md>); Go2's existing LINTRACK-125 question also has a [current-name lookup page](<experiments/go2/exp-go2-planar-tracking-terrain-progression.md>) pointing back to the original G-001 Run record. Existing `H-`, `HS-`, `G-`, `GS-`, `Rxx`, evidence IDs, report titles and filenames are historical addresses; retain them and use the [registry](<EXPERIMENTS.md>) to find their underlying records. Do not issue another ID in those four series. Release **display title/body/tag** may be migrated to the current naming standard under the dated 2026-09-29 migration rule in Release taxonomy〔원본 참조: `../docs/RELEASE_TAXONOMY.md` / 공개 사본 미포함〕; such a migration must preserve assets and record the previous title/tag as legacy addresses.

| Concept | Current meaning |
| --- | --- |
| Submission preset | `h1-submit-2`, `h1-submit-4`, `h1-submit-6`, `g2-submit-3`, `g2-submit-5`: the actual preliminary-round submission configuration, not a candidate or an experiment ID. The number is the submission round. A later preset is named only after an actual submission. |
| Experiment | A question to test, with its comparison/control and decision criterion; use a descriptive `exp-<robot>-<question>` slug, not a reward configuration as its identity. |
| Run | One actual training execution. Use the evidence run ID when available. PERSONAL/OFFICIAL, fresh/resume, seed, env count, iteration range and completion status belong to the Run, not the Experiment name. Evaluations, videos and exports are linked records, not extra training Runs. |
| Resolved config | The complete effective environment/agent settings in the native run or submitted snapshot. Do not infer missing values from a short label. |
| Override | The **final** config difference from the chosen submission preset; a human-readable display such as `h1-submit-4 + lin=0.75 + feet=0.30`, not a unique identity or a replacement for full config. Use literal signed decimal values, not compressed `075`/`m02` encodings. |
| Lineage | Parent Run and checkpoint filename/SHA, phase transitions and iteration ranges. Fresh and resume with the same final config remain distinct Runs. A return to the preset value removes that final override, but never erases the intermediate phase. |
| Legacy alias | An old hypothesis/Run label or source-era name with a link to its original evidence. It remains searchable but must not be used to issue new names. |

Reward-descriptor display names separate the abbreviation and encoded value with a hyphen: e.g. `LINTRACK-125`, `LINZ-4`, `AIRTIME-025`, `TERM-50`, `ORIENT-100`, `ACTRATE-001`, and combined `LINTRACK-150-LINZ-2`. For the current H1 reward axes, `ORIENT-100` means `flat_orientation_l2=-1.0` (**OFFICIAL fresh 3K completed 2026-10-06; PERSONAL single-policy behavior HOLD 2026-10-07**) and `ACTRATE-001` means `action_rate_l2=-0.001` (**OFFICIAL fresh3K training and separate PERSONAL video/evaluation completed 2026-10-10; single-policy behavior analysis received 2026-10-11 and policy HOLD**). These are reward descriptors, not evidence of promotion or an official score. The descriptors introduced as **PLANNED on 2026-10-09** use the existing numeric encoding: `ACTRATE-0001` = `action_rate_l2=-0.0001` and `ANGTRACK-065` = `track_ang_vel_z_exp=0.65`; **both OFFICIAL fresh3K training Runs are COMPLETED/PASS as of 2026-10-10**. ACTRATE-0001 has a separate PERSONAL model_2700 full evaluation (not an official score). Their independent Experiments are [action-rate relaxation](<experiments/h1/exp-h1-action-rate-relaxation.md>) and [angular-tracking boost](<experiments/h1/exp-h1-angular-tracking-boost.md>); the descriptors themselves do not replace actual evidence Run IDs. The bare forms `ORIENT`, `ACTRATE` and `ANGTRACK` name reward axes only, not specific candidate configurations. Unhyphenated forms such as `LINTRACK125` or `TERM50` are legacy/source spellings, not names to issue for new display titles or migrated Release metadata.

Current short override keys are `lin=track_lin_vel_xy_exp`, `ang=track_ang_vel_z_exp`, `feet=feet_air_time`, `term=termination_penalty`, `hip=joint_deviation_hip`, `linz=lin_vel_z_l2`, `angxy=ang_vel_xy_l2`, `action=action_rate_l2`, and `orientation=flat_orientation_l2`. A new key is documented with its full field name before use. Display overrides in full-field-name order; their order is not training phase order. The native resolved config and evidence, not this display, determine equality.
