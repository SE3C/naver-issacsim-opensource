# 센서·제어·강화학습 설계 판단

## 관측에서 행동까지

로봇은 카메라·라이다·자세·속도·관절 상태·지형 정보 등을 관측하고, 정책은 이를 바탕으로 속도·관절 목표 같은 행동을 낸다. 관측이 부족하면 정책은 환경을 구분하지 못하고, 보상이 잘못되면 관측을 활용하는 대신 보상 허점을 악용할 수 있다.

## 실습과 대회 학습의 경계

- 카메라·라이다 실습은 센서 데이터의 형식과 좌표계를 이해하기 위한 것이다.
- 예선 정책의 관측·학습 환경은 제공 코드가 정한 구성을 따르며, 참가자는 허용된 reward 파일을 중심으로 실험한다.
- 키보드 수동 조작은 행동 목표를 이해하고 디버깅하는 보조 수단이지 제출 정책이 아니다.

## reward 설계 원칙

- 속도 추종, 자세 안정, 발 접촉, 에너지·진동·낙상 억제는 서로 trade-off다.
- 한 항목을 과도하게 키우면 제자리 떨림, 한 발 들기, 과도한 점프, 지나친 소극성 같은 reward hacking이 나타날 수 있다.
- 기준 정책을 먼저 영상으로 보고, 하나의 가중치만 바꿔 같은 조건에서 비교한다.
- 평균 reward가 올라도 실제 지형·명령에서 실패하면 개선으로 인정하지 않는다.

## 진단 순서

1. 명령 추종 실패인지, 균형·접촉 실패인지 영상으로 분류한다.
2. 관련 reward 하나와 지형 난이도 하나만 후보로 잡는다.
3. 짧은 학습으로 방향성을 확인한 뒤 최종 후보만 길게 학습한다.
4. 결과와 설정을 실험 기록에 남긴다.
