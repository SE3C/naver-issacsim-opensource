# Isaac Sim 기초 판단 요약

## 무엇을 이해해야 하나

- Isaac Sim은 USD stage 위에 물리·로봇·센서를 올려 실험하는 환경이다.
- 강화학습은 로봇의 관절 명령을 직접 규칙으로 쓰기보다, 보상과 반복 경험으로 정책을 만드는 방식이다.
- 실습에서 중요한 것은 API를 많이 외우는 것이 아니라 **stage 초기화 → 로봇 참조 → 물리 설정 → 관찰 → 재현 가능한 실행**의 순서를 지키는 일이다.

## 안전한 실습 흐름

1. 기존 `World`·stage가 남아 있지 않게 초기화한다.
2. 기본 지면과 조명을 만들고, 공식 에셋 루트에서 USD를 불러온다.
3. 로봇의 articulation root와 초기 자세를 확인한다.
4. 한 요소만 바꿔 중력·마찰·질량·지형이 행동에 미치는 영향을 관찰한다.
5. 오류가 나면 에셋 경로, stage prim 경로, 초기화 순서, Isaac Sim 버전을 차례로 점검한다.

## H1·Go2를 다룰 때

- H1은 두 발 균형과 회복이, Go2는 접촉·험지·계단에서의 안정성이 특히 중요하다.
- 로봇 USD 경로를 하드코딩하지 말고 설치된 에셋 루트를 통해 찾는다. 버전마다 경로와 import 이름이 달라질 수 있다.
- 지형 난이도를 급격히 올리기보다 평지에서의 명령 추종을 기준점으로 만든 뒤 요철·경사·계단으로 확장한다.

## 원문이 필요한 경우

강의별 코드 전문·UI 설명은 originals의 `data/raw/lectures/`에 있다. 정확한 API 예시가 필요하면 현재 설치 환경과 함께 원문을 다시 확인한다.
