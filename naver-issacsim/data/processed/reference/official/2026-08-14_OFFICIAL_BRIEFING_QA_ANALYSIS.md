# 2026 설명회 질문 모음 — 운영 해석 분석

이 문서는 공식 Q&A 37개를 작업 판단에 필요한 규칙으로 분류한 것이다. 원문 스스로도 실제 판단이 갈리는 경우 규정집이 우선한다고 명시한다. 따라서 일정·서버 운영처럼 Q&A에만 있는 안내는 변경될 수 있으며, 제출·제재 판단에는 통합·예선·본선 규정집을 먼저 적용한다.

## 서버와 100시간

- 예선의 100시간은 **팀 합산·대회 전체 시간**이며 라운드가 바뀌어도 초기화되지 않는다.
- 서버를 켜고 하는 학습·연습·환경 확인 모두 시간이 차감된다. 코드 열람과 결과 확인은 파일을 개인 PC로 내려받아 하면 서버 시간을 쓰지 않는다.
- 30분 이상 자리를 비우면 결과를 자동 저장하고 서버가 종료된다는 안내가 있다. 작업이 끝나면 직접 종료해 시간을 보존하는 편이 안전하다.
- 100시간을 모두 써도 이미 준비한 파일은 홈페이지에서 제출할 수 있지만 새 학습·수정은 할 수 없다. 본선 진출팀의 추가 시간은 별도 공지다.
- Q&A 기준 제공 환경은 Ubuntu + RTX 5080 GPU, 팀별 분리 서버다. 같은 학교 IP나 다른 팀의 접속이 학습량에 영향을 주지 않는다고 안내한다.

## 학습 장소와 제출 이력

- 정책을 생성하는 학습과 제출 정책은 운영진 제공 서버에서 이뤄져야 한다.
- 개인·학교 장비에서는 이미 생성된 정책의 실행·관찰·영상 확인·파일 점검만 허용된다. 개인 장비에서 새로 학습한 정책으로 제출물을 대체하면 안 된다.
- AWS 등 외부 GPU 학습은 금지다. Q&A는 대회 서버의 학습 기록과 제출 정책·설정을 대조할 수 있다고 설명한다.
- 공개 논문·기술문서·저장소의 파라미터를 참고해 직접 실험하는 것은 허용하되, 다른 팀과 정책 파일·보상 설정을 주고받는 것은 금지다.

## AI·개발 도구

- LLM, Copilot 등은 개념 학습·코드 작성·디버깅·분석·번역에 사용할 수 있다. 결과물의 최종 책임과 설명 가능성은 참가자에게 있다.
- 가이드북·실습 코드는 제3자에게 제공하거나 공개하는 방식으로 외부 서비스에 올리면 안 된다. 외부 AI를 쓰더라도 공개·공유 범위를 주의한다.
- 실험 반복 스크립트나 개인 PC의 에이전트 사용은 안내상 제한하지 않지만, 제공 GPU 서버에 MCP·에이전트·외부 연결을 설치하거나 환경을 변경하면 안 된다.
- Isaac Tutor 문답은 개인정보 없이 익명화되어 교육·개선 목적으로 저장될 수 있으므로 비밀 정보·자격증명을 입력하지 않는다.

## 예선 제출·평가 실무

- 한 라운드에는 H1 또는 Go2 **한 대분**만 제출한다. 전체 순위는 로봇별 최고 점수를 합산하므로 두 로봇을 모두 제출해야 최대 200점이 가능하다.
- 제출 파일은 서버에서 내려받아 공식 홈페이지에 올리고, 보상 변경의 이유를 코멘트로 작성한다.
- 이전 라운드 정책은 그대로 재제출하거나 `--resume`, `--load_run`, `--checkpoint`로 이어 학습할 수 있다. 이어 학습은 지형 난이도가 낮은 단계로 돌아갈 수 있다는 안내가 있다.
- 튜터·사전 점수는 이상 여부 확인용이며 실제 채점 점수와 같다고 보장되지 않는다. 공식 평가는 여러 로봇을 동시에 실행해 평균을 내고, 조건이 같으면 같은 파일의 결과는 같다고 안내한다.
- 수정 대상은 `training/humanoid/humanoid_rewards.py`와 `training/quadruped/quadruped_rewards.py`다. 제공 파일의 다른 부분 수정은 피한다.

## 공유·안내·공개

- 팀 내부의 private GitHub 저장소 사용은 허용된다고 안내한다. 다른 팀과의 결과물 공유·공동 제출, 가이드북·실습 코드의 공개 저장소 업로드는 금지다.
- 공식 공지·제출·순위 확인은 홈페이지가 기준이다. Discord 접근이 어려워도 홈페이지 공지를 확인한다.
- 제출 정책·코드의 저작권은 팀에 있으나, 운영진은 운영·심사·기록·홍보·교육 목적의 복제·전시·시연·공개 권한을 가진다. 구체적 공개 경로는 별도 공지 대상이다.
