# 공개 관찰 자료

이 폴더는 공개 웹 페이지에서 읽기 전용으로 받은 자료를 보관한다. 이는 우리 팀의
PERSONAL/OFFICIAL run evidence도, 운영진의 공식 평가 원본도 아니다.

- [2026-09-22 공개 데이터 audit](./2026-09-22_ncrc_public_data_audit/README.md): NCRC 연구 기록 공개 스냅샷과 정규화 audit bundle.
- [2026-09-23 웹 snapshot](./2026-09-23_ncrc_site_snapshot/README.md): 별도 날짜의 HTML/API 원본과 보존 ZIP. 9/22 응답과 동일 snapshot으로 합치지 않는다.
- [2026-10-01 운영보드 snapshot](./2026-10-01_ncrc_status_snapshot/README.md): 운영보드 HTML 및 원본 ZIP을 복원할 수 있는 base64 보존본. 인증된 사용자 화면 snapshot이므로 공개 API 전체로 해석하지 않는다.

각 자료의 수집 범위·원본·해석 경계는 하위 폴더의 intake 문서를 따른다. 외부 관찰은
자료의 특성상 새 가설의 prior로만 쓰며, `research/EXPERIMENTS.md`의 Run·공식 성능 근거·Optuna trial에
직접 넣지 않는다.
