# [분석] Go2 R3/R5 로컬·공식 평가 불일치와 분석 방향 논의

> 관리 안내 (2026-10-13): **분석** 작업으로 분류했다. 실행 장소와 OFFICIAL/PERSONAL은 출처 정보다. 기존 본문은 당시 기록으로 보존하며 현재 상태는 [Experiment registry](../../../../../research/EXPERIMENTS.md)를 확인한다.

## 문제의식과 잠정 방향

사용자는 로컬 평가기상 점수가 올랐는데 공식 시뮬레이션 점수는 떨어진 상황에서 다음 실험 방향과 분석 로직의 전면 재작성 필요성을 질문했다. 초기 논의에서는 공식 감점 구성도 미확인이었으나, 후속 [운영진 DM 답변](../2026-10-08_GO2_R3_R5_OFFICIAL_SCORE_COMPONENTS_ORGANIZER_REPLY.md)으로 **계단 생존율 개선보다 추종 점수 손실이 컸음**을 확인했다. 로컬·공식 tracking 역전의 구체적 행동·환경 메커니즘과 reward 인과효과는 여전히 미확인이다.

현재 방향은 **평가기 유지 → 합산 점수의 단독 채택 권한 축소 → 계단 생존 이득을 유지하며 추종 손실을 회복할 수 있는지 확인 → 기존 R3/R5 자료에서 불일치 조사**다. 평가기 코드·가중치·reward는 이번 문서화에서 변경하지 않는다.

## 확인된 사실과 미확인 항목

| 남은 불일치 | 공식 tracking이 낮아진 행동·환경 메커니즘과 로컬 역전 이유는 미확정. 평균오차→Tracking Score 변환식·정확한 시나리오 조건·반복 평가 변동 폭은 미제공. |

공식 상세 수치·출처는 [R5 평가](../2026-10-08_OFFICIAL_EVAL_GO2_ROUND5_LINTRACK125.md)와 [R3 평가](../2026-09-20_SE3C_PRELIM_R3_GO2_EVALUATION_AND_ORGANIZER_REPLY.md)를 따른다. “공식 점수가 떨어졌다”는 표현은 여기서는 **시뮬레이션 점수 감소**를 뜻하며 종합 점수는 상승했다.

계단 감소 −0.17은 시뮬레이션 순감소 −0.23의 약 74%다. 이는 항목별 산술 기여이지 실패 원인 비율이 아니다. 운영진의 survival/tracking 기여 분해는 공식 감점 구성을 설명하지만, 어떤 reward가 이를 일으켰는지 증명하지 않는다. 반올림된 지표로 공식 점수를 다시 계산해 고치지 않고, 한 쌍만으로 반복 변동 폭이나 통계적 유의성을 확정하지 않는다.

운영진은 학습의 몸통 접촉 종료율이 변하는 curriculum·탐색 행동에서 측정되고, 자동평가는 고정 시나리오에서 그 행동 무작위 없이 측정된다고 설명했다. 학습 contact와 공식 survival을 서로 환산하지 않는다. 이번에는 공식 계단 survival도 개선됐으므로 “공식 점수 감소 = 낙상 증가”로 해석하지 않는다.

## 분석의 최종 판정 규칙

1. **개선 목표를 먼저 적는다.** 계단 개선 실험이라면 tracking 개선, 실제 진행·통과, stall, 낙상·몸통 접촉, 자세·회복을 나눠 판정한다. tracking error 감소만 확인됐으면 “계단 추종 개선”으로 쓰고 자동으로 “계단 성능 전반 개선”으로 확대하지 않는다.
2. **근거 세 층을 분리한다.** 학습 로그는 학습 진행·후반 안정성, PERSONAL 고정 평가·영상은 해당 조건의 행동, 공식 평가는 실제 제출 시나리오 성적을 기록한다. 로컬 점수는 공식 점수의 검증된 예측값이 아니다.
3. **합산 점수만으로 채택하지 않는다.** 평균이 좋아져도 목표 시나리오·seed별 손해와 tracking/진행/안정성 trade-off를 표시한다. 원자료에 없는 지표나 사후에 만든 임의 임계값을 측정 결과처럼 쓰지 않는다. 영상은 camera-off 평가와 같은 episode로 취급하지 않는다.
4. **후보 판정의 범위를 제한한다.** 기존 7450 PROMOTE·7050 fallback HOLD·4800 REJECT는 당시 PERSONAL 비교의 후보 판단이다. 공식 우열 판정으로 확대하지 않고 당시 분석·원문도 소급 재작성하지 않는다. 기존 reward-effect HOLD는 유지한다.
5. **한 쌍에 맞춘 점수 보정은 보류한다.** 공식 점수에 맞추려고 evaluator 가중치·calibration을 임의로 조정하지 않는다. 향후 여러 제출·checkpoint에서 불일치가 반복되는지와 평가 조건을 확인한 뒤 별도 코드 변경을 검토한다.

## 우선할 조사 — 기존 저장자료만 사용

아래는 다음 작업 제안이며 이번 문서화에서 실행하지 않았다. 새 GPU 학습·평가·영상 렌더의 승인이 아니다.

1. **정책 연결:** 기존 metadata의 checkpoint SHA로 R3 제출 actor의 original 4800과 R5 제출 actor의 terminal 7450을 연결한다. R5 automatic best 7050을 대신 비교하지 않는다. 이미 검증한 identity를 이유 없이 다시 전체 hash하지 않는다.
2. **로컬 점수 상승의 의미:** 사용한 결과 파일, scorer/protocol version, normalization/calibration, 비교 기준·입력을 확인한다. raw 진단 평균 개선과 계산된 aggregate score 상승을 별도 기록한다. 점수의 기준이나 calibration이 다르면 수치 자체를 직접 순위 비교하지 않는다.
3. **동일 목표·case·seed 대조:** 저장된 계단 상행·하행의 실제 명령 대비 x/y/yaw-rate tracking, 진행, stall, 종료·몸통 접촉, 자세 지표를 우선 비교한다. 운영진은 공식 `play.py`에서 두 정책의 계단 명령 추종을 나란히 보라고 권했다. 평균뿐 아니라 seed별·취약 case와 cohort/episode 분모를 적는다. 저장자료에 없는 통과 판정·회복 지표는 미측정으로 남긴다.
4. **영상 trade-off 확인:** 같은 지형에서 발 걸림·방향 이탈·진동·회복을 확인한다. 캡처 결함을 정책 실패로 읽지 않고 20초 생존을 완주로 바꾸지 않는다.
5. **로컬에서도 손해가 있으면:** 기존 합산 방식이 그 손해를 가렸는지 조사한다. 이를 곧바로 공식 감점 원인으로 확정하지 않는다.
6. **로컬은 일관되게 좋으면:** 공식 Tracking Score는 감소했으므로 로컬 tracking error 개선과의 조건·정의 차이를 우선 조사한다. 공개적으로 확인 가능한 task/source, command, terrain 난이도·계단 치수, reset/termination, 무작위화, 평가 시간·집계를 대조한다. 미공개 공식 조건을 추측해 “동일 평가”라고 만들지 않는다.

## 경쟁 가설과 후속 방향

- 평균·합산 점수가 일부 seed/취약 조건의 손해를 가렸을 가능성.
- tracking 이득과 진행·자세·회복·종료의 비용을 로컬 판정에서 다르게 다뤘을 가능성.
- 로컬·공식의 환경·명령·집계·채점 조건 차이 가능성.
- 공식 단회 측정의 변동 가능성.

위 항목은 **공식 점수 구성 분해** 이후에도 남은 로컬·공식 차이의 경쟁 가설이다. 공식 계단 survival 개선과 tracking 손실 자체는 운영진 답변으로 확인됐으므로 둘을 미확인 가설로 되돌리지 않는다. 향후 질문은 **“개선된 계단 생존을 유지하면서 공식 명령 추종 손실을 회복할 수 있는가”**다. 구체적 reward 변경·새 Experiment/Run 발급·재학습 계획은 아직 확정하지 않았다.

## 2026-10-09 후속 — 저장자료 대조 완료

위10/08 논의 이후 [새 심층 보고서·독립 검증](../2026-10-09_GO2_R3_4800_R5_7450_LOCAL_OFFICIAL_COMPARISON.md)을 받았다. 같은 PERSONAL protocol에서 계단 통합 오차 **0.32029→0.14852**, 실패 **15/783→4/772**, G2 오차 **0.09085→0.07699**로 개선됐지만 공식 계단·전방위 Tracking Score는 하락했다. 로컬 고정 12.5cm/직진 조건과 공식10–15cm·미공개 명령/초기조건의 coverage를 우선 확인한다. 같은 scorer/collector/config와 raw 재집계가 일치하므로 점수 보정·scorer 교체·새 reward 학습을 서두르지 않는다. 과거 PERSONAL all-around REJECT를 공식 추종 대조군 제외로 확대하지 않으며, 4800의 공식 추종 상대 우위와7450의 공식 생존 이득을 모두 보존한다. reward-effect HOLD는 유지한다. G2 자세 RMS 비용은 조건부 취약성 후보로 남긴다. 보고서의 직접 영상 관찰은 표본 관찰이며 이 문서 갱신에서 새 GPU나 프레임 분석을 실행하지 않았다. 이후 출발/전환·계단 체류·초기조건별 진단은 별도 후속 제안이다.

## 보존과 작업 범위

이번 작업은 대화 기반 분석 방향 문서와 AI context 갱신뿐이다. 원본 보고서·공식 제출 파일·frozen preset·evidence·영상·평가 결과는 변경하지 않는다. 새 GPU 실행, 평가기 재작성, Optuna trial/objective 생성, Release 변경, 서버 작업을 수행한 것으로 보고하지 않는다.
