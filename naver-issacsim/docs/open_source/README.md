## 현재 원칙

- 비공개 보관본과 공개용 배포본을 분리한다. 공개를 위해 원본 evidence를 수정하지 않는다.
- 원래 제목·본문·경로·수치·링크·줄바꿈을 유지하고 개인정보만 블라인드한다. 부분 재작성이 필요한 자료는 파일 단위로 제외하며 공개 안내는 `_publication/`에만 둔다.
- 공식 코드·강의·실습·규정 원문·운영진 DM은 자체 코드와 같은 라이선스로 묶지 않는다.
- 파일뿐 아니라 Git 이력·태그·Release·중첩 압축본까지 공개 범위를 결정한다.
- 개인 이메일·사용자 경로는 실제 자격증명과 구분하여 처리한다. 자격증명이 발견되면 삭제만으로 끝내지 않고 폐기·교체 여부를 확인한다.
- 브랜치 삭제·이력 재작성·라이선스 확정·공개 전환은 별도 결정 후 진행한다.

## 백업과의 관계

Downloads의 `NCRC_5REPO_ARCHIVE_20261023_PARTIAL_LFS`는 5개 저장소와 Release를 보존한 별도 로컬 폴더다. 압축본 10개와 검증·복원 안내를 부모 폴더째 보관한다. 공개용 자료가 아니므로 이 저장소에 압축본을 추가하지 않는다.

과거 LFS 이미지 96개(306,487,951 bytes)는 미복구다. 따라서 이 백업만을 근거로 기존 이력이나 이전 백업을 파기하지 않는다. 이번 준비 문서 추가는 백업 생성 이후의 변경이므로 기존 압축본에는 들어 있지 않다.
