## 조사 분담

서브에이전트 8개가 아래 범위를 병렬 조사했다. 메인이 최종 선택·공개 사본 편집·통합을 담당했다.

1. 평가기 코드·테스트·런처
2. sidecar 코드·fixture·공식 원문 내장 여부
3. 분석·지식·registry·원문 구분
4. NVIDIA 자체 setup·운영 wrapper와 공식 training 구분
5. Originals 결과물과 제공 자료의 권리 근거
6. 현재 파일의 자격증명·개인정보와 비식별 기준
7. 152 Release·600 asset의 공개 후보 분류
8. 외부 의존성과 자체 설명 문서

## 로컬 공개용 사본

workspace의 `naver-issacsim-opensource/`에 evaluation, sidecar, server_tools, knowledge를 둔다. 학습 task·원문·모델·압축본·기존 Git 이력은 복사하지 않는다.

- 평가기 20개 source 파일: core/collector/CLI, Windows·Linux 실행기, CPU 테스트, bundle manifest와 자체 점수 명세.
- sidecar 37개 source 파일: 원문 keeper 1개를 제외한 원래 추적 파일. 해당 원문을 문자열로 내장한 테스트도 공개 사본에서 제거하고 안내를 수정했다.
- 서버 도구 11개 source 파일: setup 및 자체 scripts 전체. 공식 training 코드는 없음. 외부 training 배치에 의존하는 과거 wrapper는 standalone이 아니라고 안내한다.
- 파일별 원본/공개 사본 SHA와 출처 commit은 `CANDIDATE_SOURCE_MAP.json`에 기록한다.
- 자체 실험 방법론과 공개 사용법은 새로 작성한다. 원문 분석 보고서·운영진 대화를 통째로 재게시하지 않는다.

고정 경로 `C:\NCRC`, `/home/shadeform`, 외부 task 참조가 있다는 사실만으로 자체 도구 전체를 제외하거나 기능을 재설계하지 않는다. 실제 자격증명과 개인정보는 구분한다. 코드가 실행 중 외부 소스를 archive에 복사할 수 있는 경우 그 결과물의 공개 검토가 별도로 필요함을 명시한다.

## 더 살릴 자료

분석 저장소는 추적 파일 872개이며 research 57개, 자체 실험 문서/산출물 176개, AI library 22개를 후보군으로 조사했다. 이들은 모두 공개 확정이 아니지만 자체 해석·방법·가설·그래프를 제공 원문·DM·개인정보와 분리하면 추가할 여지가 있다. 일반화한 실험 방법론을 먼저 공개 사본에 작성했다.

Release asset 600개는 초기 분류상 평가 ZIP 후보 33개, metadata/제출 자료 추가 검토 100개, 미검사/권한 확인 archive 467개다. 저장소 위치만으로 영구 제외를 결정한 것이 아니다. 큰 archive는 공식 소스·자체 결과가 섞여 있으므로 공개용 결과 요약이나 비식별 평가 묶음을 별도로 만드는 방향을 검토한다.

## 계속 미확정인 사항

후속 사용자 결정: 내용을 요약·재해석하거나 링크를 치환하지 않고, 원래 저장소 이름별 폴더와 내부 경로를 유지한다. 426개 선별 파일 중 422개는 원본 바이트 동일, 4개는 개인 프로필 경로만 블라인드했다. 이전 공개 안내·링크 치환·인용 요약은 현재 사본에서 걷어냈다. 제공 소스 fixture와 제3자 피드백 전사 등은 파일 단위로 제외했다. Release도 원래 실험 단위 33건, 원래 제목·설명·애셋 99개를 보존하는 방식으로 전환하며 원본 비공개 Release는 변경하지 않는다. 아래 1차·2차 조사 수치는 당시 기록이다.

위 수치는 1차 후보 조사 기록이다. 후속 8개 분야 검토로 분석·연구·운영 지식·그래프·구조화 산출물 247개의 공개 사본과 평가 ZIP 33개의 공개 파생본을 실제 게시했다. 평가 ZIP 33개는 더 이상 미검사 후보가 아니며, 원본/공개 변환·원격 게시 검증은 `PUBLICATION_LOG.md`에 기록한다. 원본 archive 467개와 부속 자료 100개 전부를 검사하거나 게시한 것은 아니다.

- 라이선스와 팀·외부 기여분의 재배포 권리
- 대회 진행 중 결과 공유 범위 및 종료 후 허용 범위
- 운영진·수신 보고서 원문의 공개 동의
- 모든 중첩 archive 내부의 자료/자격증명·이미지 속 식별정보
- 기존 LFS 이미지 96개 미복구 상태. 이전 보관 이력을 삭제하지 않는다.

공개용 새 저장소 생성과 원본 저장소 공개 전환은 다른 작업이다. 기존 5개의 공개 설정·이력·Release는 변경하지 않는다. 준비 문서 추가 후에는 기존 장기 압축본이 최신 작업까지 포함한다고 표현하지 않는다.
