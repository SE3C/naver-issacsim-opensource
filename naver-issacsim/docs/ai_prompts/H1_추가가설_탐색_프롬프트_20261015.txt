이 요청은 새 H1 가설 탐색 세션용이다. 첨부 H1_NEW_SESSION_HYPOTHESES_20261015.zip만을 전달 자료로 삼아, 오늘 추가 학습할 가치가 있는 H1 가설을 찾아줘. 이전 대화를 알고 있다고 가정하지 마. Optuna 코드 검토·개선 세션과는 별개이며, 기존 가설 선정 보고서는 ZIP 안에 포함되어 있다. 같은 내용을 다시 요약하는 것으로 끝내지 마.

목적은 후보 수 늘리기가 아니라 제한된 실제 학습에서 얻을 정보와 개선 가능성을 높이는 것이다. 기존 1순위 lin=.55 resume +2K, 2순위 action=-.0003 fresh3K도 경쟁 후보로 남겨두고, 더 나은 후보가 없으면 없다고 결론 내도 된다. Optuna 개선은 별도 작업이므로 여기서는 프로그램·새 목적함수·자동 탐색을 만들지 마.

분석 순서:
1. START_HERE.md, curated/의 최신 수납 문서로 상태를 정리하고, sources/의 원문·CSV로 필요한 주장만 확인해. 서로 같은 평가를 재인용한 보고서는 독립 증거로 세지 마. 입력에 없는 파일을 읽었다고 쓰지 마.
2. 기존 완료 실험과 미실행 계획을 구분해. lin=.65 fresh와 ACT 부모에서의 resume, 같은 이름 model4650의 서로 다른 SHA, fresh 조합과 한 항목 변경을 섞지 마. 과거 계획 문서는 현재 수납 상태보다 우선하지 않는다.
3. 아직 설명되지 않은 병목을 먼저 2~3개로 정의해. H1 정지·H3 횡명령의 body/world 좌표, H4 yaw, H5 rough 진행/하위 꼬리/stall의 trade-off를 구분하고, 왜 그 reward 항목이 그 병목에 영향을 줄 수 있는지 물리·학습 메커니즘과 반례를 함께 써줘. 최종 world 잔차가 작다는 이유로 추종 성공으로 판정하지 마.
4. 이미 허용·활성화된 reward weight 변경 범위에서 후보를 검토해. 새로운 reward 활성화, PPO/terrain/command/curriculum/termination 코드 변경은 제외해. 정확한 현재 설정·활성 여부를 자료에서 확인할 수 없으면 확인 필요로 표시해. 기존 body-rate/airtime 계획도 최신 결과를 근거로 재평가하되 미실행을 성공으로 취급하지 마.
5. 최종 후보는 최대 3개, 실제 오늘 우선 실행 추천은 1개와 예비 1개만 제시해. 각 후보에 기준 preset, 전체 override, 부모 대비 실제 변경, fresh/resume, 부모 Run/checkpoint/SHA 또는 부모 없음, 요청 iteration, 기존 대조군, 기대 개선·부작용, 반증 관측을 적어줘. 비교군이 없거나 선택 checkpoint/학습 길이가 다르면 숨기지 마. 전체 native 설정을 확인하지 못했다면 완전 재현 설정이라고 주장하지 마.
6. 새 후보가 기존 lin=.55 또는 action=-.0003보다 왜 더 유리한지 '가설 식별력 / 기존 증거 / 학습 비용 / 최악 실패 위험'으로 비교해. 근거 없는 숫자 확률·예상 공식 점수·가짜 채택 임계값은 만들지 마. 평가가 포착하지 않는 stairs/boxes 완주를 개선했다고 예측하지 마.

제약: 첨부는 기존 보고서와 파생 CSV 중심이다. 원 episode/MP4 전체나 native 훈련 archive는 포함하지 않았다. 파생 수치 재계산과 독립 raw 재분석을 구분하고, source_run_id=null 및 imported-parent provenance=false/null을 외부 SHA 연결로 덮어쓰지 마. evaluator cohort/seed는 독립 훈련 반복이 아니다. PERSONAL 보조 평가를 공식 점수로 환산하지 마.

시간 배분: 기존 비교 재계산은 의사결정이 달라질 부분만 하고, 중복 통계/그림을 늘리지 마. 증거가 약하면 '새 탐색 후보'로 낮춰 제시해도 된다. 새 GPU 학습·평가·영상·export·서버 조작·Optuna trial은 실행하지 마. 실행 명령이나 추정 서버 경로 대신 검증할 설정과 실험 설계만 줘. 새 Run ID/legacy H·HS 번호를 발급하지 마.

최종 결과는 한국어 보고서, 후보 비교표 CSV, 사용한 근거와 계산 파일(새로 만들었다면)을 모두 포함한 단일 ZIP으로 반환해. 보고서 맨 앞에는 '오늘 1순위 / 왜 기존 후보보다 나은지 또는 기존 후보 유지 / 변경값 / fresh·부모 / iteration / 실패 시 알 수 있는 것'을 짧게 써줘. 실행되지 않은 가설을 완료 결과로 기록하지 마.
