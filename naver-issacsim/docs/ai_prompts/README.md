# AI 분석 지침·프롬프트의 현재/역사 구분

- [`지침.txt`](./지침.txt): 현재 사용하는 공통 AI 사용자 지침. 실행 환경·공식 규정의 개별 규칙이 충돌하면 그 환경 규칙이 우선한다.

2026-10-17 서버 안내 단순화: “서버 켰다/이 값으로 진행”은 신규 서버의 최초 준비와 운영진 baseline을 기준으로 안내한다. 현재 서버 재사용이라는 명시나 현재 출력이 있으면 그 상태를 반영한다. 과거 실험 완료는 현재 설정이 남았다는 근거가 아니다. 이 시작 상태에서 목표와 다른 reward만 설정하며, 새 H1 baseline에서 `h1-submit-2 + lin075 + action0001`은 lin·action·termination 세 항목만 변경한다. 이 예시는 실제 공통 지침에도 포함했다. 준비부터 완성 세션명의 attach까지 한 답변에 주고, 전체 값 재설정·전체 표·조건부 선택 목록·불필요한 중간 보고를 생략한다. 사용자 전달본은 Downloads의 `프롬프트.txt`다.
- [`1분석_개정_비교형.txt`](./1분석_개정_비교형.txt): 명시적으로 요청한 영상·평가 ZIP 심층 분석에 사용하는 템플릿. 연결된 GitHub 커넥터가 있으면 관련 제출·공식 점수 이력을 읽기 전용으로 확인하며, 정책 identity와 공식/내부 지표를 구분한다. 접근 불가여도 ZIP 분석은 계속한다. “숫자만” 같은 좁은 요청의 범위를 자동 확대하지 않는다.
- [`Optuna_개선_기존세션_프롬프트_20261015.txt`](./Optuna_개선_기존세션_프롬프트_20261015.txt) · [Optuna 패킷 안내](./Optuna_개선_패킷안내_20261015.md): **기존 Optuna 분석 세션**에서 최소 PC Ask/Tell 개선본을 요청한다. 실제 학습·GPU 실행 권한이 아니다.
- [H1 추가 가설 탐색 프롬프트](./H1_추가가설_탐색_프롬프트_20261015.txt) · [패킷 구성·한계](./H1_추가가설_패킷안내_20261015.md): **별도 새 세션**에서 기존 권고와 새 후보의 정보 이득을 비교한다. 새 Run·계획 선택·Optuna 실행은 없다.
- [2026-09-23 과거 공통 지침](historical/README.md): **그 시점의 원문 버전**을 그대로 보존한 역사 기록. 현행 OFFICIAL 서버 종료·게시·GPU 권한을 결정하지 않는다.

지침을 검토하거나 재사용할 때 제목과 작성 시점을 확인한다. 과거 스냅샷을 제거하거나 현행 문서를 덮어쓰지 않는다.

2026-10-17 분석 템플릿 갱신: 공식 제출 목적과 보조 지형 관찰을 분리하고, 다음 학습의 질문(config·학습 seed·학습량·전환 경로)을 명시한다. 결과는 보고서와 실제 생성한 재현 파일의 단일 ZIP으로 전달한다. 현재 사용자 파일은 Downloads의 `분석 프롬프트.txt`와 동기화한다.
